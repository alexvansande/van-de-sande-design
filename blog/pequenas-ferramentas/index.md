Aplicativos gigantes sempre vão ter o seu lugar, mas assim como na internet, as vezes programas com um uso específico feitos por um time de 3 ou 4 desenvolvedores as vezes conseguem ser mais práticos, eficientes, menos bugs e serem muito mais agradáveis de usar. E como muitas vezes eles trabalham juntos, a soma das partes faz a experiência de usar um colosso como o Dreamweaver tão agradável quanto usar o software de imposto de renda eletrônico.

Essa é a minha receita. Aceito sugestões.

1-O design em si, ninguém escapa do photoshop..

2-Instale o [Quicksilver](http://www.blacktree.com/). É a cola que junta tudo.

3-Abra uma janela do preview com o design.

4-Para acessar e mesmo editar arquivos direto do ftp: [Cyberduck](http://cyberduck.ch/).

5-Configure o [CSSEdit](http://macrabbit.com/cssedit/) como editor externo de CSS no Cyberduck. Este é um dos programas mais bem feitos que já vi.

6-Usando o quicksilver chame o [Xscope](http://iconfactory.com/software/xscope). Um programinha hiper simples com uma série de ferramentas como réguas, lupas e guias para voce colocar por cima de qualquer janela.

7-Use [Backdrop](http://www.johnhaney.com/backdrop/), o 2o programa mais simples do mundo: uma tela preta pra tapar as outras janelas.

8-Se você tiver uma tela grande (ou dois monitores) pode colocar o preview e o css edit lado a lado e ir copiando usando essas réguas o layout literalmente pixel por pixel. O css edit ainda usa o colorpicker do OS X que permite que você puxe para seus elementos exatamente a cor que estiver em qualquer janela.

9-Para editar os htmls eu uso o [Smultron](http://smultron.sourceforge.net/) que é opensource e faz o básico de um notepad. Graças a comunidade já fizeram até [mesmo um set de ícones melhor](http://www.shinze.com/index.php/post/2006/09/18/142-a-new-set-of-icons-for-smultron) para ele.

10-Poderia continuar listando: [Colorschemer](http://www.colorschemer.com/online.html), [Disco](http://www.discoapp.com/), [Growl](http://growl.info/), [Galleria](http://www.colorschemer.com/galleria_info.php)
